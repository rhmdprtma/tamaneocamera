## 📸 FOTO & VIDEO

**FOTO:** Pose -> Pencet 📸 FOTO -> Ke-save `tama-....png`
**VIDEO:** Pencet 🎥 VIDEO -> Pose -> ⏹ STOP -> **BAGIKAN / SIMPAN KE FOTO** -> Simpan Video

Nama file: `tama-video.mp4` — langsung bisa upload ke TikTok / IG, gak perlu convert.
Apa yang lu liat di layar = apa yang ke-save. Mirror + Cover udah pas.

## 🛠️ TEKNOLOGI

- **HTML + CSS + JavaScript** — Tanpa framework, biar ringan
- **MediaPipe Hands** — Deteksi 2 tangan, real-time
- **MediaPipe Face Mesh** — Deteksi wajah buat Sensor
- **MediaRecorder + Canvas captureStream** — Buat rekam video
- **GitHub Pages** — Hosting gratis

## 📱 JADIIN APLIKASI DI HP

1. Buka link kamera di Chrome / Safari
2. Pencet **Share / Bagikan**

4. Beres, ikon TAMA nongol di HP lu
